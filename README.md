## Cómo reproducir

1. Clonar este repositorio y abrir `Tarea3_MendezLemuel.Rproj` en RStudio.
2. En la Terminal, desde la raíz del proyecto, clonar la base del docente:
   `git clone https://github.com/PotoyJuarez/CA0204-Tarea3-base.git base`
3. Ejecutar (Source) `cod/01_datos.R`: genera `data/transacciones_2025.csv`,
   `data/cantones.csv` y `config/parametros_tarea3.csv`.
4. Renderizar `Tarea3_MendezLemuel.qmd` para obtener `Tarea3_MendezLemuel.html`.
5. El libro `excel/Tarea3_MendezLemuel.xlsx` lee la base con Power Query
   (actualizar la ruta de origen si se cambia de computadora).
